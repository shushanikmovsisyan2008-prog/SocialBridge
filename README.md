# SocialBridge — սոցիալական աջակցության հարթակ

Հարթակը ներկայացնում է սոցիալական աջակցության վեց ուղղություն՝ ընտանիք, սնունդ, բարեկեցություն, աշխատանք, բնակարան և համայնքային կապեր։ Յուրաքանչյուր ծառայության էջում ավելացված է գործնական գործողությունների պլան, որը կարելի է հարմարեցնել տվյալ իրավիճակին։

## Գործարկում
- Պահանջվում է Java 21 կամ ավելի նոր տարբերակ։
- Windows-ում գործարկեք `mvnw.cmd spring-boot:run`, իսկ macOS/Linux-ում՝ `./mvnw spring-boot:run`։
- Բացեք http://localhost:8080։
- Լռելյայն օգտագործվում է տեղային H2 տվյալների բազա։ MySQL-ի համար սահմանեք `DB_URL`, `DB_USERNAME` և `DB_PASSWORD` միջավայրի փոփոխականները։
